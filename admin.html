OTOMASYON & WEBHOOK

Instagram, YouTube & GitHub Otomasyonu

Instagram ve YouTube paylaşımlarını 7/24 takip botuyla, GitHub repolarını tek tıkla veya webhook ile otomatik aktar.

7/24 Otomatik Takip Botu

rss.app üzerinden Instagram veya YouTube kanalın için aldığın RSS adresini ekle. Sunucu botu her 10 dakikada bir kontrol edip yeni gönderileri otomatik yayınlar.

GitHub Repolarını Çek

GitHub kullanıcı adını girerek son güncellediğin açık kaynak depolarını tek tıkla sosyal akışına aktarabilirsin.

GitHub Anlık Webhook Bilgileri

GitHub repolarına yeni kod veya sürüm attığında bloguna anında düşmesi için aşağıdaki bilgileri kullan:

Nasıl Çalışır?

1. Instagram & YouTube (7/24 Takip Botu)

Soldan eklediğin rss.app veya YouTube RSS adresleri sunucu tarafından 10 dakikada bir otomatik taranır. Yeni paylaşım bulunduğunda fotoğrafıyla birlikte bloguna eklenir.

2. GitHub (Anlık Push / Release)

GitHub reponda Settings → Webhooks → Add webhook bölümüne gir. Payload URL kısmına yukarıdaki Webhook URL'ini, Content type olarak application/json, Secret kısmına da Gizli Anahtarı yapıştır.
