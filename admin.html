OTOMASYON & WEBHOOK

GitHub, Instagram & LinkedIn Otomatik Paylaşım

Diğer platformlarda paylaştığın anda gönderilerin bloguna otomatik düşmesi için bağlantıları buradan yönet.

GitHub Repolarını Çek

GitHub kullanıcı adını girerek son güncellediğin açık kaynak depolarını tek tıkla sosyal akışına aktarabilirsin.

Anlık Webhook Bilgileri

GitHub Webhooks, Make.com, Zapier veya n8n üzerinden anlık gönderi aktarmak için aşağıdaki adresi ve gizli anahtarı kullan:

Platform Bağlantı Rehberi

1. GitHub (Anlık Push / Release)

GitHub reponda Settings → Webhooks → Add webhook bölümüne gir. Payload URL kısmına yukarıdaki Webhook URL'ini, Content type olarak application/json, Secret kısmına da Gizli Anahtarı yapıştır.

2. Instagram (Make.com / n8n)

Make.com veya n8n'de "Instagram: Watch Media" modülünü "HTTP: Make a Request (POST)" modülüne bağla. Header'a X-Webhook-Secret ekle, Body olarak platform: "instagram", title, excerpt, image ve url gönder.

3. LinkedIn (Make.com / n8n)

Aynı şekilde LinkedIn paylaşım tetikleyicisini aynı Webhook URL'ine platform: "linkedin" JSON'u gönderecek şekilde bağlayabilirsin.
